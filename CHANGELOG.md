# Changelog

## 2.0.1

Documentation and CI only; no change to the specified controls or the
reference package.

- Add chapter 13, the operational case: accepted maintenance delivered to a
  private integration's development branch, with its evidence limits stated
  (no completed autonomous lifecycle is claimed).
- Restore the complete responsible-development article
  (`docs/articles/apollo-2-responsible-development.md`) and link it from the
  README.
- Lessons learned: a parallel-agent test leak and an escape that could not be
  closed (`docs/08-lessons-learned.md`, with related notes in the agents and
  hooks chapters).
- Conformance workflow: one fixed `NODE_OPTIONS` value on every Node major.

## 2.0.0

- Specify project-independent responsible AI development controls with evidence
  and failure actions, finite execution, independent exact-head/base review,
  truthful completion and reviewed learning.
- Add a portable standard-library local evidence validator and conspicuously
  synthetic two-project conformance tests with an explicit runtime coverage gap.
- Retire marker-only approval helpers and remove the inline marker gate from
  the settings fragment. Historical examples are informative, not normative.
- Preserve the memorial, MIT license and useful historical case-study chapters.

This release description does not assert publication, live controller delivery,
provider backend identity or certification. Those require their own evidence.
